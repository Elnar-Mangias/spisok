# План покупок

Небольшое приложение на React для списка покупок.

## Возможности
- Добавление товара и его цены в сомах.
- Отметка купленных товаров и удаление отдельных позиций.
- Подсчёт общей стоимости и прогресса.
- Автоматическое сохранение списка в `localStorage`.
- Адаптивный интерфейс для мобильных устройств.

## Запуск локально

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## GitHub Pages

В репозитории открой **Settings → Pages** и выбери **GitHub Actions** в разделе Build and deployment. После push в ветку `main` workflow из `.github/workflows/deploy.yml` соберёт приложение и опубликует папку `dist`.
